# ScientificInquiry_R
Biostat in R workshops for FUV_CORE104 Scientific Inquiry 
Last update: May 2026

This repository contains material for teaching an introduction to biostatistics in R as workshops part of the COR104 Scientific Inquiry course taught at Fulbright University Vietnam. The workshop covers basic uses of R implemented into RStudio, from data loading, exploration, analysis, to graph building and some fun art. It includes a simple analysis of variance. I some datasets shared in The Analysis of Biological Data, 3rd edition, by Michael Whitlock and Dolph Schluter book (a good introduction to statistics for biologists (https://whitlockschluter3e.zoology.ubc.ca/index.html#Data).
